# 🏠 Airbnb Clone (Full Stack)

A complete listings and booking platform built as part of the **SapphireIQ Full Stack Development Internship**.

## 🚀 Live Demo
- **Frontend (Live):** [https://airbnb-clone-psi-pied.vercel.app/](https://airbnb-clone-psi-pied.vercel.app/)
- **Backend API:** [https://airbnb-clone-hy9g.onrender.com](https://airbnb-clone-hy9g.onrender.com)

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, React Router, Axios
- **Backend:** Node.js, Express.js, MongoDB (Mongoose)
- **Authentication:** JWT (JSON Web Tokens) & bcryptjs
- **Database:** MongoDB Atlas
- **Deployment:** Vercel (Frontend) + Render (Backend)

## ✨ Features Implemented
- **Module 1 - Backend Foundation:** Complete REST APIs, Data Modeling (User, Listing, Booking, Review), JWT Auth Middleware.
- **Module 2 - Listings & Search:** Responsive UI, Real API Integration, Clean Listing Grid.
- **Module 3 - Booking Flow:** Date-picker integration, Backend Overlap Validation (prevents double booking), Past-date blocking.
- **Module 4 - Reviews & Dashboard:** Review aggregation (average rating), Role-based Host Dashboard.
- **Module 5 - Deployment:** Fully deployed live platform with separated frontend/backend environments.

## ⚙️ Local Setup
1. Clone the repo.
2. **Backend:** `cd backend` -> `npm install` -> add `.env` variables -> `npm run dev`.
3. **Frontend:** `cd frontend` -> `npm install` -> `npm run dev`.
